# Accessibility (A11Y)

**Core Requirements:**
- **Keyboard & Focus**: Full keyboard navigation support and highly visible focus states.
- **Screen Readers**: Use proper semantic HTML and ARIA labels.
- **Visuals**: Large touch targets (min 44x44px). High contrast ratios. Never use color alone as a status indicator (always pair with text/icons).
- **Motion**: Respect `prefers-reduced-motion` to disable unnecessary animations.
- **Media**: Captions are MANDATORY on all learning videos. Do not rely on audio-only cues.
- **Language**: Use simple text and support local-language UI strings.
