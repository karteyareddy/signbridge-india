# UI / UX Guidelines

**Design Direction:**
- **Aesthetic**: Calm, trustworthy, and human. Not flashy or over-engineered. Use deep blue/indigo + soft neutral surfaces, with accessible teal/cyan for positive actions.
- **Typography**: Large, highly readable system sans-serif fonts (e.g., Inter).
- **Interactive Elements**: Large touch targets (min 44px) with clear verbs (e.g., "Start learning").
- **State Management**: Every interface must elegantly handle four states: Loading (skeleton or spinner), Success, Empty (clear CTA when no data), and Error (helpful fallback message).
- **Clarity**: Status must never rely on color alone. Always pair color changes with text or recognizable icons.
