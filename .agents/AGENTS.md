# Project Rules: SIGNBRIDGE INDIA

These rules apply globally to all agent interactions in this workspace.

- **PRD is the source of truth.** Do not invent features.
- **Do not change architecture without explaining why.**
- **Inspect existing code before modifying it.**
- **Do not duplicate existing components or utilities.**
- **Never store raw camera frames by default.**
- **Never expose secrets or service-role keys.**
- **Never fabricate AI accuracy numbers.**
- **Never describe the MVP as a universal ISL translator.**
- **Every AI prediction must have a confidence state.**
- **Low-confidence predictions must trigger a safe fallback.**
- **Basic Access Point functionality must work without account creation.**
- **Service packs must support offline usage.**
- **All UI must be mobile-first and accessibility-aware.**
- **Every feature must handle: loading, success, empty, and error states.**
- **Do not modify unrelated files.**
- **Prefer simple architecture over unnecessary abstractions.**
- **Run linting, tests, and production build before declaring a feature complete.**
